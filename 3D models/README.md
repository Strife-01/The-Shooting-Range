Shooting Range 3D models
===
This directory contains all the 3D models used to encase the hardware needed. The models were created in Autodesk Fusion.

---

Printing the model
---
The models of the main casing for the gun were intended to be printed with the round side down as to preserve the middle parts, which need to be more detailed. 
The fittings are quite tight, which means it is recommended to sand down sections that do not fit smoothly.
